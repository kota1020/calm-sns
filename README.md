# Calm — インスタとTikTokを「フォロー中だけ」で見るiPhoneアプリ

**リールもおすすめも出ない。見るのは自分がフォローした人だけ。**

インスタやTikTokを開くと、気づけばリールやおすすめを何十分も見ている。
Calm は、SNSを「やめる」のではなく、アルゴリズムに流される部分だけを取り除いて、フォローしている人の投稿だけを見られるようにするアプリです。

---

## どういうアプリか

| | 本物のアプリ | Calm |
|---|---|---|
| インスタのリール | 出る（無限にめくれる） | 出ない（タブも消す・めくって次へ進めない） |
| インスタの発見・おすすめの投稿・広告 | 出る | 出ない |
| インスタのストーリー・DM | ある | ある |
| TikTokのおすすめ（For You） | 出る | 出ない。フォロー中だけ |
| TikTokの保存・いいね・リポスト | ある | ある（下の「プロフィール」） |
| 使った時間 | 自分では分かりにくい | iPhoneのスクリーンタイムから、日ごとに見られる |

本物のインスタ・TikTokは、iPhoneのスクリーンタイムの仕組みで開けなくします（Calmの「止める」）。SNSはCalmの中からだけ見る、という使い方です。

## 画面

| 画面 | できること |
|---|---|
| ホーム | 今日のSNSの時間。インスタ・TikTokのアイコンを押して開く。コピーしたリンクをCalmで開く |
| インスタ | ホーム（上にストーリー）・DM・自分のページ。リール・発見・おすすめの投稿・広告は隠す |
| TikTok | フォロー中の動画だけ。保存ボタン付き。下の「プロフィール」で保存・いいね・リポストを見る |
| 時間 | iPhoneのスクリーンタイムの数字。35日分のグラフ（押すとその日のアプリ別）、今日「止める」をオフにした回数 |
| 止める | 本物のインスタ・TikTok（ほかのアプリも選べる）を開けなくする。ホーム画面・ロック画面のウィジェットからワンタップで切替 |
| 設定 | ログイン・ログアウト、アプリごとの設定（検索を止める・広告を消す など） |

## 入れ方（1コマンド・初回5分くらい）

要る物

- Mac と Xcode（App Storeから無料。一度開いて、Settings → Accounts で Apple ID を足す）
- 有料の Apple 開発者登録（本物のアプリを止める機能が、この登録でしか動かないため）
- iPhone（ケーブルでMacにつなぎ、ロックを解除して「このコンピュータを信頼」）

```sh
git clone https://github.com/kota1020/calm-sns.git
cd calm-sns
./install.sh
```

`install.sh` が、足りない道具（xcodegen）を入れ、チームID（開発者のID）とつないだiPhoneを自動で探し、作ってiPhoneに入れます。何か足りない時は、何をすればいいかを日本語で出します。

入った後、iPhoneで1回だけ

1. 設定 → プライバシーとセキュリティ → デベロッパモード をオン（出ていれば）
2. 設定 → 一般 → VPNとデバイス管理 → 自分の Apple ID →「信頼」
3. Calm を開き、「止める」→「許可する」（スクリーンタイムの使用）
4. インスタ・TikTok を開いてログイン（ログイン情報はiPhoneの中だけに残ります）

## しくみ

- インスタ・TikTok は、ウェブ版をアプリの中で開いています。`Resources/calm.js` が、リール・おすすめ・広告などの部分を隠し、行ってはいけないページ（リール一覧・For You など）に移ろうとしたらフォロー中へ戻します
- 本物のアプリを開けなくするのは、Apple の Family Controls / ManagedSettings（スクリーンタイムの仕組み）
- 時間の数字は DeviceActivityReport（iPhone のスクリーンタイムそのもの）。Calm が自分で数えているわけではありません
- TikTok のウェブ版（携帯向け）には保存ボタンが無いため、押すと見えない所でパソコン向けのページを開き、そこの保存ボタンを押しています
- 通信はインスタ・TikTok 本体とだけ。Calm 自身のサーバーはありません

## フォルダ

```
Sources/      画面（ホーム・SNS・時間・止める・設定）
Resources/    calm.js（インスタ・TikTokの画面を整える）、アイコン
Report/       スクリーンタイムの数字を読む部品
Widget/       「止める」のウィジェット
Shared/       止めるのオン・オフ（本体とウィジェットで共通）
install.sh    1コマンドで入れる
```

## 注意

- インスタ・TikTok の画面は各社のウェブ版です。各社がページを変えると、隠す所がずれることがあります（`calm.js` を直せば戻ります）
- 個人で使う前提のアプリです。各サービスの利用規約は自分で確かめてください
- Instagram・TikTok は各社の商標です。アイコン画像はリポに含めず、`install.sh` が App Store の公開画像を取ってきます
